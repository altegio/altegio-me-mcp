# Code of conduct

Treat contributors and users with respect. Discuss behavior and evidence; welcome
questions and corrections. Harassment, discrimination, threats and sharing
another person's private information are unacceptable.

This applies to repository issues, pull requests and project discussions.
Maintainers may edit or remove harmful content and restrict participation when
necessary. Decisions should be proportionate and explain how the behavior violated
these expectations.

Report concerns privately to [Mike Kondakov (@kondamih)](https://github.com/kondamih)
through the existing Altegio contact channel. Before public launch, the owner must
confirm an accessible private reporting route as described in
[publication decisions](docs/open-source-readiness.md).
